# 进程操作、连接筛选、CSV 导出与整机网速设计

## 1. 目标与范围

在现有 NetAssess Windows GUI 中补充日常运维操作：从主进程列表定位可执行文件或结束指定进程；在连接明细中按 IP 和端口筛选；从主表和连接明细导出当前结果；明确显示排序方向并稳定列表滚动位置；在主窗口状态栏显示整台服务器所有活动网卡的实时总速率。

目标平台继续为 Windows Server 2016 及以上 Desktop Experience、x64、管理员权限。保持现有 ETW 进程与连接统计口径、单主定时器、稳定行键更新和静态 MSVC 运行库部署方式。

## 2. 主进程列表操作

### 2.1 右键菜单

进程行的右键菜单按下列顺序提供操作：

1. 查看连接明细；
2. 打开文件所在位置；
3. 结束进程。

菜单继续作用于被右键的进程实例。键盘上下文菜单与鼠标右键使用同一目标行判定。

### 2.2 打开文件所在位置

程序根据所选 PID 查询完整可执行文件路径，并启动资源管理器选中该 EXE 文件，而不是只打开所在文件夹。路径查询或资源管理器启动失败时显示操作名称和 Windows 错误码。对于已结束、受保护或路径不可读的进程，不猜测路径。

### 2.3 结束进程

结束操作只针对所选进程，不递归结束子进程树。执行前显示包含进程名和 PID 的确认框。

确认后重新打开进程并读取创建时间，与列表行保存的 `ProcessInstanceId` 比较。只有 PID 和创建时间均匹配时才调用 `TerminateProcess`；进程已退出或 PID 已复用时拒绝操作并提示。访问被拒绝、受保护进程、创建时间查询失败和结束失败均显示 Windows 错误码。成功发出结束请求后刷新主列表，但进程最终退出状态仍以之后的存活检查为准。

进程路径查询、实例核对和结束操作封装在小型 `ProcessActions` 模块中，并通过可替换的 Windows API 边界测试；自动化测试不得真正结束系统进程。

## 3. 连接明细筛选

连接明细窗口列表上方增加：

- “IP 筛选”输入框；
- “端口筛选”输入框；
- “导出 CSV”按钮。

IP 筛选对格式化后的本机 IP 和对端 IP 做不区分大小写的包含匹配。空值不限制结果。IPv4 和 IPv6 均使用界面当前显示的标准文本形式进行匹配。

端口筛选为空时不限制结果；非空时必须是 `0` 到 `65535` 的单个十进制整数，并匹配本机端口或对端端口。非法文本不应用为筛选条件，界面给出明确提示。筛选条件改变后立即重建当前显示结果并回到列表顶部，不影响后台连接累计、速率基线或其他进程的明细窗口。

## 4. CSV 导出

主窗口工具区和连接明细窗口分别增加“导出 CSV”按钮。导出内容是该窗口当前筛选、当前排序后的全部行，与用户看到的结果和列顺序一致，不受滚动位置或选中状态影响。

保存使用标准 Windows 文件保存对话框，默认扩展名为 `.csv`。用户取消保存属于正常操作，不显示错误。写入采用 UTF-8 BOM，便于 Windows Excel 直接识别中文。字段包含逗号、双引号、回车或换行时用双引号包围，字段内双引号写成两个双引号。写入或关闭文件失败时显示 Windows 错误码，不报告成功。

CSV 字段编码与转义集中在共享 `CsvExporter` 模块；两个窗口只负责提供列标题和当前显示行。

## 5. 排序标记与滚动策略

### 5.1 排序箭头

两个 ListView 点击列名后，当前排序列标题显示 Windows 原生升序或降序标记，其他列清除标记。首次点击新列为升序，再次点击同一列切换方向；主表和连接明细原有默认排序保持不变。筛选不会改变当前排序列或方向。

### 5.2 滚动状态

每个列表维护两种状态：

- 自动置顶：窗口初始、筛选条件变化或用户点击列名重新排序后启用；每次定时刷新确保第一行位于顶部。
- 保持用户位置：检测滚动条操作、鼠标滚轮以及 Page Up、Page Down、Home、End 和方向键等手工滚动；当用户离开顶部后，定时刷新按稳定行键恢复原顶部行及选择项。

用户手工回到第一行时恢复自动置顶。程序自身为恢复位置而执行的滚动不得误判为用户滚动。列表为空或原顶部行已被筛选/删除时，选择最接近的有效位置；自动刷新不得强制跳回顶部。

主表和连接明细复用一个小型列表视图辅助模块来更新列头排序标记和维护滚动意图，避免两份行为漂移。

## 6. 整机网卡实时总速率

新增 `NetworkRateMonitor`，每次主窗口一秒定时刷新时读取所有运行状态为 Up 的物理和虚拟网络接口累计收发字节，排除软件环回接口。统计独立于 ETW 进程流量，因此包含无法归属进程的流量。

每个接口按稳定接口标识保存上一采样值和单调时钟时间。首次出现、重新连接、计数回退或时间差非正时，该接口本次速率为 0；接口消失时移除其基线。各接口用自己的有效增量求速率，再汇总为整机上行、下行及合计速度，避免接口热插拔产生异常峰值。累加使用饱和或受检运算，最终格式沿用现有 1024 进制速度格式。

主状态栏追加：`总网速：↑ <上行>/s ↓ <下行>/s 合计 <总计>/s`。读取失败时保留其他状态信息，并显示网速不可用和 Windows 错误码；下一次定时器继续重试。

优先使用 Windows IP Helper API 的接口统计，并动态/兼容地限定到 Windows Server 2016 已提供的 API。构建增加所需系统库，不增加第三方依赖或后台线程。

## 7. 布局、DPI 与错误处理

新增控件沿用现有系统字体、DPI 缩放和窗口最小尺寸策略。主窗口在现有按钮区放置导出按钮；连接窗口在列表上方增加筛选和导出工具区。窗口缩放及 `WM_DPICHANGED` 后重新计算控件位置和列宽。

所有用户触发失败均以明确操作名称和系统错误码显示。可取消操作只有结束进程确认框和保存对话框；取消不视为错误。定时刷新中的网卡读取错误不弹出重复消息框，只在状态栏显示。

## 8. 测试与验收

自动化测试至少覆盖：

- 进程路径查询、PID 复用保护、确认后结束调用及错误传播；
- 网卡首次采样、正常增量、多个接口汇总、接口增删、计数回退、非正时间差、环回排除和 API 错误；
- IP 包含筛选、端口双端匹配、空筛选和非法端口；
- 主表和明细表导出当前筛选/排序结果；
- CSV UTF-8 BOM、中文、逗号、引号、回车和换行转义；
- 两个列表的排序箭头切换；
- 排序或筛选后置顶、用户滚动后保持位置、手工回顶后恢复自动置顶；
- 新增控件创建失败和 Windows 错误码传播。

完成后执行 Debug/Release 构建和全部 CTest，检查 x64 Windows GUI、`requireAdministrator` 清单、Common Controls 清单和仅系统 DLL 的动态依赖。

手工验收在管理员权限的 Windows Server 2016 或以上 Desktop Experience 环境执行：验证资源管理器选中 EXE；结束一个专门启动的无关测试进程；观察物理与虚拟网卡流量；操作两个列表的滚轮、滚动条和键盘；导出的 CSV 用 Excel 打开并核对中文和列顺序。不得用生产服务进程验证结束功能。

## 9. 明确不包含

- 结束进程树、暂停进程、调整优先级或服务管理；
- 多端口范围、正则表达式、CIDR 或保存筛选预设；
- 定时自动导出、追加导出或历史数据库；
- 按网卡拆分展示、利用率百分比或链路容量估算；
- 解析报文内容或改变现有端口推断协议规则。
